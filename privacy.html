별도 회원가입 없이 플레이하며, 기본 게임 진행은 기기에 저장합니다. 앱의 외부 SDK는 기기 밖으로 정보를 전송할 수 있습니다. 개발자는 결제 카드·계좌 정보, 연락처, 정확한 위치, 사진·음성에 접근하는 기능을 제공하지 않습니다.

이메일 문의·삭제 요청회신 이메일, 문의 내용, 이용자가 선택해 제공한 앱 버전·구매 관련 정보고객 지원·권리 행사·본인 확인. 필요 이상의 개인정보는 보내지 마세요.

Firebase Analytics에는 광고 ID 수집과 광고 개인화 신호를 사용하지 않도록 설정되어 있습니다. 이 설정은 AdMob의 광고 ID 처리까지 해제하는 설정은 아닙니다. 현재 분석 수집은 기본 활성화되어 있으며 게임 설정에 별도 분석 끄기 버튼은 없습니다.

게임이 직접 기록하는 분석 이벤트는 게임 준비·재방문(game_ready, return_session), 첫 이용 단계(first_session_step), 저장 불러오기·복구 결과(save_load_result, save_recovered), 콘텐츠 시작·완료(level_start, level_end), 건설 시작·완료(building_upgrade_started, building_completed), 작전 완료·숙련(operation_completed, operation_mastered), 보상 정산 실패(reward_settlement_failed), 재화 획득(earn_virtual_currency)입니다. 콘텐츠에는 일반 전투·재전투·침공·일일 던전·심연의 탑·계약·주간 균열·왕관 기록이 포함됩니다.

후속 이벤트는 전투 패배·보스 승패(battle_defeated, boss_defeated, boss_victory), 상점 열람·접수된 구매 시도(shop_opened, purchase_attempt), 의상 장착·구매(costume_equipped, costume_purchased), 의상 구매 시 실제 재화 소비(spend_virtual_currency), 펫 소환·광고 보상 경로 소환(pet_summoned, pet_ad_summoned), 실제 보상형 광고 시청 완료(rewarded_ad_completed)입니다. 진행 단계·레벨·등급, 콘텐츠·건물 구분, 성공 여부, 재화 종류·수량·획득 경로 등 제한된 값만 함께 기록합니다. 구매 시도는 결제 성공을 뜻하지 않으며, 광고 보상 경로 소환은 광고 제거 혜택 사용을 포함할 수 있습니다.

마계 서열전은 Unity Gaming Services(익명 로그인·Cloud Save·Leaderboards)를 사용합니다. 서열전을 이용하면 별도 회원가입 없이 기기별 익명 플레이어 ID가 만들어지고, 닉네임, 서열전 점수·시즌, 공개 방어 편성(부대 구성과 대전에 필요한 레벨·등급·능력치 값), 최근 공격 기록이 Unity 서버에 저장됩니다. 닉네임·점수·공개 방어 편성은 순위표와 상대 목록을 통해 다른 이용자에게 공개됩니다. 닉네임에는 실명·연락처 등 개인을 알아볼 수 있는 정보를 쓰지 마세요. 순위표는 매주 월요일 09:00(한국 시각)에 초기화됩니다. Unity Analytics 및 Firebase Remote Config는 현재 별도 도입하지 않았습니다. 알림은 기기 내 예약 알림입니다.

2. 보유기간과 파기

정보기간·삭제 기준
기기 내 저장·진단 파일이용자가 Android 앱 저장공간의 데이터 삭제를 실행할 때까지 보관됩니다. 자동 휴면 삭제나 원격 삭제 기능은 없습니다. OS·기기 백업에 남은 사본은 별도 관리가 필요할 수 있습니다.
Firebase 분석이번 출시 준비 기준은 이벤트·사용자 수준 데이터 14개월 보관입니다. 운영자가 실제 Analytics 속성의 보유기간과 새 활동 시 기간 갱신 설정을 확인해야 하며, 현재 14개월로 적용되었다는 뜻은 아닙니다. 기간이 지난 데이터는 제공사의 정기 삭제 절차에 따르며 집계 보고서에는 동일한 기간이 적용되지 않습니다. Google 보유기간 안내의 설정값과 대조한 뒤 게시 문구를 확정합니다.
AdMobGoogle이 광고·측정·보안 목적과 정보 종류에 따라 보유합니다. 단일 보유기간을 개발자가 지정하거나 즉시 전체 삭제를 보장하지 않습니다. Google 보유기간 안내를 참고하세요.
Unity Gaming Services(마계 서열전)서열전 서비스를 제공하는 동안 보관하며, 삭제 요청 시 해당 익명 플레이어 ID의 닉네임·점수·공개 방어 편성·공격 기록을 삭제합니다. 지난 시즌 순위 보관본의 보유기간은 운영 설정 확정 후 이 방침에 안내합니다.
Unity IAP공식 안내상 서비스 로그는 90일, 주문 등은 개인정보처리자 또는 이용자의 삭제 선택 시까지 보유합니다. 실제 적용 범위와 법정 보존 예외는 처리 주체에 확인합니다.
개발자가 보관하는 거래·분쟁 기록법정 보존 대상인 계약·청약철회 및 대금결제·재화 공급 기록은 5년, 소비자 불만·분쟁 처리 기록은 3년 보존 후 파기합니다. 개발자가 수집하지 않은 기록을 별도로 보유한다는 의미는 아닙니다.
일반 문의·삭제 요청처리 목적 달성 후 지체 없이 삭제합니다. 소비자 분쟁 기록으로 보존이 필요한 경우에는 위 3년 기준을 적용합니다.

삭제 대상 전자 파일은 복구하기 어려운 방법으로 파기하고, 법정 보존 대상은 해당 목적에 한해 접근을 제한하여 보관한 뒤 파기합니다.

3. 외부 처리자·제공 및 국외 이전

Google은 광고 서비스의 처리 주체이며 Firebase 분석을 처리합니다. Google Play는 결제를 처리하고 Unity IAP는 결제 연동을 담당합니다. 서비스와 계약에 따라 처리위탁과 제3자 제공에 해당하는 범위가 달라집니다. 광고 SDK의 직접 수집을 포함하므로 “외부 제공이 전혀 없다”고 안내하지 않습니다.

이전받는 자·연락처국가·시기·방법항목·목적보유·이용기간
Google LLC — 개인정보 문의미국. 앱 실행·분석 이벤트·광고 요청·동의 확인·결제 시 SDK의 암호화된 네트워크 전송위 분석·광고·결제 항목. 이용 통계, 광고 제공·측정, 결제, 보안·부정 이용 방지Firebase는 위 보유기간 운영안·실제 속성 설정 확인 대상. 광고·결제는 Google 목적별 보유정책 및 법정 보존 기준.
Unity Technologies 및 해당 계약상 계열사 — dpo@unity3d.com미국 등 Unity 처리 지역. 결제 SDK 이용·진단 시 암호화된 네트워크 전송. 실제 수신 법인·추가 국가 확인 필요위 Unity IAP 식별자·거래·진단 항목, 서열전 익명 플레이어 ID·닉네임·점수·공개 방어 편성·공격 기록. 결제 연동·복원·진단, 서열전 상대 찾기·순위표 운영 및 보안위 Unity IAP 기간 및 위 서열전 보유기간.

Google은 개인정보처리방침에 따라 미국 외 국가에서도 정보를 처리할 수 있습니다. 실제 추가 이전 국가와 수신자별 보유기간, 계약 이행에 필요한 위탁·보관인지 별도 동의가 필요한 제공인지에 대한 법적 근거는 출시 전 확정할 사항입니다. 이 초안의 게시만으로 국외 이전 동의를 받은 것으로 간주하지 않습니다.

국외 이전 거부·처리정지·삭제는 개발자 이메일로 요청할 수 있습니다. 게임 설정의 “광고 개인정보 설정”에서 제공되는 동의 선택을 변경하거나 Android의 광고 설정에서 광고 ID를 삭제·재설정할 수 있습니다. 거부하면 관련 광고 보상·결제 기능이 제한될 수 있습니다. 광고 선택 변경만으로 Firebase 분석 전송이 중단되지는 않습니다. 현재 분석 전송을 즉시 멈추려면 앱 사용을 중단해야 하며, 저장 데이터 삭제가 이미 전송된 정보의 삭제를 뜻하지는 않습니다.

4. 이용자 및 법정대리인의 권리

분석 수집 중단·처리정지 또는 삭제를 원하면 계정·데이터 삭제 요청 안내를 통해 요청해 주세요. 현재 앱에서 분석만 즉시 끄는 기능은 없습니다. 추가 전송을 피하려면 요청 처리 전 앱 사용을 중단할 수 있습니다. 앱 데이터 삭제는 기기 내 기록 삭제이며 이미 전송된 분석 기록을 지우거나 다음 실행의 분석 수집을 끄는 조치가 아닙니다. 광고 개인정보 설정·광고 ID 삭제도 Firebase 분석 중단과 별개입니다.

개인정보 열람·정정·삭제·처리정지 및 동의 철회를 요청할 수 있습니다. 계정·데이터 삭제 요청 안내 또는 modelmap.studio@gmail.com으로 연락해 주세요. 확인 가능한 최소 정보로 요청자를 확인하고 처리 결과와 제한 사유를 안내합니다. 현재 앱 안에 계정·전체 데이터 삭제 메뉴는 없습니다. 분석 식별자와 이메일이 자동 연결되지 않으므로 특정 분석 기록 식별이 어려울 수 있으며, 가능한 범위와 제공사 절차를 안내합니다.

5. 아동 및 대상 연령

서비스의 목표 이용자층은 만 16세 이상이며 만 13세 미만 아동을 대상으로 하지 않습니다. 이는 콘텐츠 이용등급과 구별되는 대상 연령 안내입니다. 만 14세 미만 아동의 개인정보를 동의가 필요한 방식으로 처리해야 하는 경우에는 법정대리인 동의 등 법정 절차가 필요합니다. 해당 정보의 부적절한 수집을 알게 되면 확인 후 필요한 삭제·보호 조치를 진행합니다.

SDK 제공사의 HTTPS/TLS 전송 보호를 이용합니다. 로컬 저장 파일을 암호화 저장한다고 보장하지는 않습니다. 개발자 보유 자료의 접근을 업무상 필요한 범위로 제한하며, 개인정보 문의 담당은 온담 스튜디오입니다. 연락처: modelmap.studio@gmail.com.
