  • 계정·데이터 삭제 요청

출시 전 검토용 초안입니다. 현재 앱에는 계정·전체 데이터 삭제 메뉴가 없으며, 이메일로 삭제 요청을 받는 방식입니다. 요청 처리와 외부 제공사 삭제 절차는 출시 전 운영 확인이 필요합니다.

마왕의 딸 키우기 · 온담 스튜디오
기준일: 2026-10-18
문의: modelmap.studio@gmail.com

1. 이메일로 개인정보 삭제 요청

  1. 데이터 삭제 요청 이메일 보내기를 누르거나 위 주소로 제목 “데이터 삭제 요청 - 마왕의 딸 키우기”를 보내 주세요.
  2. 삭제할 범위(문의 기록, 구매 관련 기록, 분석 정보 등), 사용한 앱 버전과 회신 이메일을 알려 주세요. 문의 이력이 있으면 해당 메일에 이어서 요청해 주세요. 필요할 때만 최소한의 추가 확인 정보를 요청합니다. 카드번호·비밀번호·신분증 전체 사본은 보내지 마세요.
  3. 요청 접수 후 지체 없이 확인하고, 삭제 가능 범위·필요한 확인 절차·처리 결과 또는 법정 보존 사유를 회신합니다. 확인되지 않은 일괄 처리 기한이나 즉시 삭제를 보장하지 않습니다.

설정 화면에 삭제용 플레이어 ID가 표시되는 기능은 현재 확인되지 않았으므로 ID 제출을 필수로 요구하지 않습니다. 이메일과 Firebase 앱 인스턴스 ID는 자동 연결되지 않습니다. 식별할 수 없는 분석 자료를 삭제했다고 안내하지 않으며, 확인 가능한 식별 수단과 Google·Unity의 요청 절차를 안내합니다.

2. 기기에 저장된 게임 데이터 삭제

현재 기본 게임 저장은 기기 내부에 있습니다. Android 설정 → 앱 → 마왕의 딸 키우기 → 저장공간 → 데이터 삭제(기기에 따라 “저장용량 비우기”)를 이용하면 앱의 로컬 진행·재화·설정·저장 및 로컬 기록을 지울 수 있습니다. 메뉴 이름은 기기별로 다릅니다. 이 작업은 되돌릴 수 없으며 복구되지 않는 진행·소모 재화가 생길 수 있습니다. OS·기기 백업에 있는 사본은 별도로 관리해 주세요.

개발자는 이메일만으로 기기의 저장 파일을 원격 삭제할 수 없습니다. 앱 삭제·데이터 삭제는 Google Play 구매 이력이나 이미 전송된 분석·광고 데이터를 삭제하지 않으며 환불도 자동으로 진행하지 않습니다.

3. 삭제 범위와 외부 서비스

  • 개발자가 보유한 문의·지원 자료와 식별 가능한 개인정보는 법정 보존 예외를 제외하고 삭제합니다.
  • Firebase 분석 자료는 식별 가능한 경우 제공사 절차에 따라 요청을 처리합니다. 익명화된 집계 자료는 개인별로 분리하여 삭제할 수 없을 수 있습니다.
  • Google 광고 및 결제 기록은 Google 개인정보 안내에 따른 권리 행사 절차를 이용할 수 있습니다. Android 광고 ID 삭제는 과거 모든 광고 기록 삭제와 같지 않습니다.
  • Unity IAP의 위탁 처리 자료는 개발자가 확인 후 Unity에 요청하고, Unity가 독립적으로 처리하는 자료는 unity-iap-contact@unity3d.com으로 직접 요청할 수 있습니다.
  • 현재 경쟁전 UGS 인증·클라우드 저장 연결은 비활성화 상태입니다. 존재하지 않는 클라우드 계정의 삭제를 보장하지 않습니다. 기능 활성화 전 별도 삭제 절차를 마련합니다.

4. 보존되는 자료

개발자가 보유하고 법정 보존 대상인 계약·청약철회 및 대금결제·재화 공급 기록은 5년, 소비자 불만·분쟁 처리 기록은 3년 보존 후 파기합니다. 일반 문의는 목적 달성 후 삭제합니다. Firebase의 실제 보유기간은 출시 전 확인 대상이며, Google·Unity의 독립 보유 자료에는 각 제공사의 정책과 법정 보존기간이 적용됩니다. 확인되지 않은 “백업 30일 후 완전 삭제” 약속은 하지 않습니다.

전체가 아닌 일부 자료의 삭제·열람·처리정지도 같은 이메일로 요청할 수 있습니다.
